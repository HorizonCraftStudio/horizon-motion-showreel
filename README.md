# Horizon Motion Showreel

create a minimalistic website of my 3d motion design studio, Use the attched image as the logo of the my studio Horizoncraft Studio use cal sans font for the name. Begin the website with full screen of the logo with white background, as the user scrolls the logo scales down and moves to top left corner of the hero section header and a showreel video will fade in and start playing while a paragraph of text is overlayed on the video
